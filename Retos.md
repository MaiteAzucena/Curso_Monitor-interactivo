# ¿Cuánto he aprendido? 

RETO 1: Menús y Pizarra digital
Enunciado
Utilizando el menú flotante debes hacer un recorte de todas las opciones del menú principal HOME y enviar esta captura a la pizarra digital. Colocarás la captura en la parte superior de la pantalla y debajo escribirás al menos dos de las funciones a las que podemos acceder desde este menú principal.

RETO 2: Mirroring – Proyección inalámbrica
Enunciado
Debes generar con el monitor un Hot Spot (punto de acceso inalámbrico), para compartir Internet con tus compañeros(as). Una vez realizado este paso, utiliza el sistema de proyección inalámbrica (EsharePRO) para proyectar desde un dispositivo móvil o un ordenador. 
Configura el modo Moderador, para que se necesite una autorización previa del moderador para proyectar o compartir archivos.

RETO 3: Selección de fuentes de entrada
Enunciado
Conecta un ordenador al monitor interactivo de forma que pueda ser operado desde el propio monitor. Desde el monitor, abre un documento de Word en el ordenador y escribe: “¡Qué maja es la profe 😊!”.

RETO 4: Active y modo dividido
Enunciado
Abre dos aplicaciones al mismo tiempo: una página web con el contenido que tú quieras y un archivo PDF almacenado en el monitor de forma local. Utiliza la función Lápiz (capa de anotación), para destacar un contenido interesante de la web abierta. Después, haz que el archivo PDF se presente en forma de miniatura y desplázalo al extremo superior derecho de la pantalla.

RETO 5: Utilidades del monitor
Enunciado
Lanza una pregunta desde el monitor para que te contesten tus compañeros desde sus dispositivos móviles. Debes darles un minuto para que te contesten y después comprueba el resultado obtenido.
